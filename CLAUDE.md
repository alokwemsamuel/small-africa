# Project rules for Small Africa

- Languages: JavaScript (ES2022+), React with JSX, PHP 8.1, HTML, CSS/Tailwind. Never TypeScript.
- File types: .js, .jsx, .php, .html, .css, .mjs for Node scripts. Never create .ts or .tsx files.
- Work only inside this project folder. Never touch my other projects or their databases.
- Keep the folder structure documented in README.md ("Project structure") and follow it for new files.
- Validate data at runtime with Zod on the frontend and server-side validation in PHP.
- Use JSDoc comments only where they genuinely help (API data shapes, money/wallet functions, shared hooks). Keep them short.
- Write clear, readable code with short comments explaining *why*, not *what*.
- Run lint, tests and a build before every commit. Commit locally; ask before pushing.
- Explain changes to me in simple, plain English.
